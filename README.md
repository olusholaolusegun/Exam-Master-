AI Quiz Platform - Frontend

## Overview
This is the frontend for the AI Quiz Platform, which provides an intelligent quiz and exam generation system. The platform allows users to take AI-generated quizzes, access premium features, and view reports on their performance.

## Features
- User authentication using Firebase
- AI-generated quiz and exam questions
- Premium features (e.g., PDF downloads, access to advanced quizzes)
- Responsive and modern UI

## Technologies Used
- React.js
- Firebase Authentication
- Firebase Firestore (for database)
- Stripe for payment integration
- Tailwind CSS (for styling)
